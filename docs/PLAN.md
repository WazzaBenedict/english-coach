# 學習計畫與工具設計

## 一、適用對象與目標

| 項目 | 內容 |
| --- | --- |
| 起點 | 基礎英文程度（約 CEFR Pre-A1 到 A1） |
| 適用 | 聽力較弱、特別是高頻聽力較差的學習者，一般學習者也適用 |
| 3 個月目標 | 能和外國人進行日常溝通（A2） |
| 長期目標 | IELTS 高分（8 分以上，C1 到 C2 等級） |

### 對目標的誠實評估

- **3 個月能溝通：做得到。** 每天 60 到 90 分鐘，專攻高頻單字、生存會話和「聽不清楚時怎麼辦」的溝通句型，三個月可以到 A2，能應付自我介紹、點餐、問路、簡單聊天。
- **1 年 IELTS 8.5：非常困難。** 8.5 接近母語者水準，多數學習者從 A1 到這個分數需要好幾年。這份計畫把 8.5 當成長期方向，一年內設定可檢驗的里程碑：6 個月 B1（約 IELTS 4.5 到 5），12 個月 B2（約 IELTS 6 到 6.5）。如果每天能投入 3 小時以上並且有真人對話練習，進度可以更快，工具會持續陪你往上走。

### 高頻弱聽對學英文的影響

英文的子音 /s/ /ʃ/ /f/ /θ/ /t/ /k/ /tʃ/ 能量集中在高頻，正好是最難聽到的部分，像 `sip / ship / tip / chip` 聽起來可能幾乎一樣。因此工具的設計原則是：

1. **文字永遠在場。** 所有聲音都有字幕，播放時逐字標示。
2. **看得見的發音。** 用音標加上嘴型、舌位、氣流的文字說明教發音，不依賴「聽出差別」。
3. **聲音可調。** 語速、音高、語音人選都能調，建議搭配耳機或助聽器。
4. **用眼睛得到回饋。** 口說練習用語音辨識把你說的話轉成文字，對照原句標出哪些字沒被辨識出來。
5. **靠上下文補足。** 訓練用句子的意思推測聽不清的字，並優先教會「請再說一次」「請寫下來」這類溝通修復句型。

### IELTS 弱聽考生的特殊安排

IELTS 對聽力障礙考生提供特殊安排，例如聽力測驗使用耳機或擴音設備、讀唇版聽力測驗（由考官朗讀）、口說測驗延長時間等。需要事先附上醫療證明向考場申請，一般要提前 6 週，需要特製試卷時要提前 3 個月。實際項目以報名考場的說明為準，報名前請先聯絡考場。

## 二、四階段路線（52 週）

| 階段 | 週次 | 目標 | 每日時間 | 重點 |
| --- | --- | --- | --- | --- |
| 1 生存溝通 | 1 到 12 | A2，能日常對話 | 60 到 90 分 | 高頻單字 800、12 個會話場景、基礎文法、發音與辨音 |
| 2 流暢表達 | 13 到 26 | B1 | 90 到 120 分 | 單字到 2000、聽寫、長一點的對話、開始閱讀短文、每週一次真人對話 |
| 3 學術入門 | 27 到 40 | B2，IELTS 入門 | 120 分以上 | 學術單字、IELTS 口說三部分、Task 2 寫作結構、閱讀題型 |
| 4 考試衝刺 | 41 到 52 | IELTS 模考 | 120 到 180 分 | 每週完整模考、錯題檢討、口說寫作限時練習、申請特殊安排 |

## 三、工具功能

| 模組 | 功能 | 弱聽輔助 |
| --- | --- | --- |
| 今日任務 | 依階段產生每日清單、連續天數、進度統計 | |
| 單字 | 間隔重複（SRS）閃卡、單字表、自訂單字 | 音標、例句文字、可調語速 |
| 會話 | 12 個場景對話、逐句播放、跟讀 | 逐字標示、中文對照、語音辨識回饋 |
| 聽力 | 辨音（最小對比）、聽寫 | 嘴型提示、可無限重播、可慢速 |
| 發音 | 高頻子音與常見難音的嘴型說明 | 完全以視覺與觸覺提示教學 |
| 文法 | 10 課基礎文法加測驗 | |
| IELTS | 考試介紹、弱聽安排、口說題庫加計時、寫作練習加字數統計 | 口說轉文字、語速（每分鐘字數）顯示 |
| 設定 | 語音、語速、音高、每日新字數、資料匯出匯入 | |

## 四、技術選擇

- 純靜態網頁（HTML、CSS、JavaScript），不需要安裝或建置，可直接用 GitHub Pages 發佈，手機和電腦都能用。
- 學習紀錄存在瀏覽器的 localStorage，可匯出成 JSON 備份。
- 語音使用瀏覽器內建的 Web Speech API（朗讀與辨識）。建議使用 Chrome 或 Edge。
- 可安裝成 PWA，離線也能使用。
- 內容都放在 `data/` 資料夾，之後可以直接加單字、對話和題目。
