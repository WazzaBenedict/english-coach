# English Coach 英文教練

為聽力較弱的學習者設計的英文學習工具。每天一堂照順序做的課，從基礎出發，目標三個月能和外國人慢速對話，再一路往 IELTS 前進。

完整的學習計畫與設計理由在 [docs/PLAN.md](docs/PLAN.md)。

## 怎麼使用

**線上使用（建議）：** 到 GitHub 儲存庫的 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main` 和 `/ (root)`，儲存後一兩分鐘就能用 `https://<你的帳號>.github.io/<儲存庫名稱>/` 開啟。手機打開後可以「加入主畫面」當成 App 使用，離線也能用。

GitHub 免費帳號只有**公開**儲存庫能開 GitHub Pages。儲存庫裡沒有個人資料（學習進度存在各裝置和你的私人 Gist，不在儲存庫裡），公開是安全的。

**跨裝置同步：** 到 App 的「設定 → 跨裝置同步」，照畫面上的三個步驟建立一組只有 gist 權限的 GitHub 權杖並貼上。每台裝置貼同一組權杖，進度會自動存到你的私人 Gist：開啟 App、切回 App、每次練習完都會同步。兩台裝置各自離線練習後再連線，紀錄會自動合併，不會互相覆蓋。

**在自己電腦上：** 下載後在資料夾裡執行 `python -m http.server 8000`，再用瀏覽器開 `http://localhost:8000`。直接點兩下 `index.html` 也能用，但語音辨識需要透過 `localhost` 或 `https` 才能啟用麥克風。

建議使用 **Chrome 或 Edge**，語音朗讀和語音辨識的支援最完整。

## 功能

第二版依據一份研究報告重新設計（學習科學、教學法、英文結構、聽損學習、IELTS），規劃與理由在 [docs/PLAN.md](docs/PLAN.md)。

**每日引導課**是主軸：首頁只有一顆「開始今天的課」，照順序做完約 25 分鐘。12 個單元共 48 堂，每單元 3 堂一般課加 1 堂整合課，學完後進入複習課。

| 一般課 | 整合課 |
| --- | --- |
| 複習、今日會話、新單字、跟讀、組句、聽寫、辨音、看中文說英文 | 複習、整段對話、替換練習、角色扮演、文法、短文閱讀、「我可以」自我檢核 |

其他頁面是自由練習：

| 頁面 | 內容 |
| --- | --- |
| 單字 | 間隔重複複習。單字卡是看英文想中文，課程學過的句子會變成看中文說英文的卡片。可加入自訂單字 |
| 會話 | 12 個場景對話，逐句播放、慢速播放、跟讀 |
| 聽力 | 辨音（20 組最小對比）與聽寫 |
| 發音 | 12 組發音的嘴型、舌位、氣流說明 |
| 文法 | 10 課基礎文法與測驗 |
| IELTS | 建議第四階段再開始。考試介紹、聽障考生安排、口說題庫、寫作練習 |
| 學習路線 | 分段目標與 12 個「我可以」檢核 |
| 設定 | 口音（英國或美國，預設英國）、語音、語速、音高、字尾標示、跨裝置同步、資料匯出匯入 |

## 聽力輔助設計

- 所有聲音都有文字，播放時逐字標示目前唸到哪裡。
- 容易聽不見的字尾（-s、-ed、縮寫）在句子裡畫底線，把「聽不見的文法」改用眼睛學。
- 語速可調到 0.4 倍，每句都有慢速鍵。第一次開啟時會帶你試聽並選出最清楚的聲音。
- 辨音不計分，答完提示如何用嘴型和母音長度分辨。
- 語音辨識只當參考，任何口說練習都可以自己按「說對了」。
- 第二個單元專門教「請說慢一點」「請寫下來」這類溝通句型。
- 連續天數休息一天不中斷，忙的日子有 5 分鐘版。

## 資料

學習紀錄存在瀏覽器的 localStorage。開啟同步後，另外會存一份到你自己 GitHub 帳號的私人 Gist，不經過其他伺服器。沒開同步時請定期到「設定」匯出備份。

## 擴充內容

內容都在 `data/` 資料夾，用文字編輯器就能加：

- `words.js`：每行一個單字，格式是 `單字|詞性|音標|中文|例句|例句中文`
- `dialogues.js`：會話場景
- `grammar.js`：文法課與測驗題
- `sounds.js`：發音說明與辨音題
- `ielts.js`：口說與寫作題庫
- `units.js`：12 個單元的目標、替換句型、短文
- `plan.js`：分段目標與提示
